## 🔧 Changements Techniques Détaillés

### Fichiers de Configuration Modifiés
```bash
# Configuration principale du modèle
src/prompts/chat/config.json
- "model": "gpt-4.1-mini" → "gpt-4.1"

# Fichiers d'environnement
.localConfigs.playground
env/.env.playground.user
env/.env.local.user
env/.env.cotechnoe            # Production
env/.env.dev.user
- AZURE_OPENAI_DEPLOYMENT_NAME: gpt-4.1-mini → gpt-4.1
```

### Workflow de Déploiement
```bash
# Commandes exécutées
make deploy ENV=cotechnoe        # Déploiement des ressources
make auto-publish ENV=cotechnoe  # Publication avec auto-incrémentation
```
