## 🔄 Migration depuis v1.1.8

### Actions requises

1. **Aucune migration de données nécessaire**
2. **Vérifier les variables d'environnement:**
   - `TEAMS_APP_VERSION=1.1.9` (déjà à jour)
   - Nouveau TEAMS_APP_ID pour environnement `dev`
3. **Déployer la documentation:**
   ```bash
   cd appPackage
   make deploy-docs
   ```
